## Quick Reference

### Essential Commands

| Task | Command |
|------|---------|
| Start development server | `mkdocs serve` |
| Build for production | `mkdocs build` |
| Build with PDF export | `ENABLE_PDF_EXPORT=1 mkdocs build` |
| Validate configuration | `mkdocs config` |

### Key Files

| File | Purpose |
|------|---------|
| `mkdocs.yml` | Main configuration file |
| `docs/index.md` | Homepage content |
| `requirements.txt` | Python dependencies |
| `docs/stylesheets/extra.css` | Custom CSS styles |

### Important Concepts

- **Conventional Commits**: Structured commit messages for better changelog generation
- **Git Integration**: Automatic tracking of page updates and contributors
- **Material Theme**: Modern, responsive theme with dark/light mode support
- **PDF Export**: Generate publication-ready PDF versions of your documentation
- **Mermaid Diagrams**: Create flowcharts, sequence diagrams, and more
